# 双目 OV5640 同步采集与 UDP 千兆以太网传输（安路 FPGA）

在安路 FPGA（TD 工具链，Verilog）上实现双路 OV5640 摄像头的硬件同步采集与实时网络传输，
上位机用 Python 接收并显示双目画面。

## 数据通路

```text
OV5640(左) ─┐
            ├─> 异步 FIFO 同步(深度 8192) ─> 32bit 拼接 ─┐
OV5640(右) ─┘  以左目 hsync/vsync 为主同步               │
                                                         ▼
                          UDP 封装(32B 包头 + 848B 载荷) ─> GMII/RGMII 千兆发送
                                                         │
                                                         ▼
                                              上位机 Python 实时显示
```

## 关键参数

| 项目 | 值 |
| --- | --- |
| 分辨率 | 640 × 480 |
| 像素格式 | 左右目各 16 位 RGB565，拼成 32 位 |
| 单帧数据量 | 640 × 480 × 4 = 921600 字节 |
| UDP 包头 | 32 字节（魔数 0xAA0055FF、宽、高、总长、偏移、图片序号、包序号、包长） |
| 单包载荷 | 848 字节（212 像素） |
| 每帧包数 | ≈ 1088 |
