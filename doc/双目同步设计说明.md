# 双目同步设计说明

## 为什么需要同步

两片 OV5640 各自输出自己的 hsync / vsync / pclk，即使配置完全一致，上电后帧起始
也会有几行到几帧的随机偏差。直接把两路画面拼在一起会出现「左眼比右眼快半帧」，
做立体匹配时视差整片偏掉。

## 采用的做法

以**左目的 hsync / vsync 作为全局主同步信号**，右目数据先写入一块异步 FIFO
（深度 8192，跨左目与右目两个像素时钟域），再由左目时钟域按行读出。这样输出的
32 位像素（左目 RGB565 高 16 位 + 右目 RGB565 低 16 位）天生对齐到同一行、同一列。

## 关键参数

- FIFO 深度：8192
- 输出位宽：32 bit（左右目各 16 bit RGB565）
- 分辨率：640 × 480
- 单帧数据量：921600 字节

## 调试要点

1. 先确认两片摄像头的 SCCB 配置完全一致（同一份初始化表即可）。
2. 用示波器同时抓两路的 vsync，确认帧率一致再调 FIFO 深度。
3. FIFO 深度不够时表现为画面右侧出现旧帧残留；深度过大只是多耗 BRAM，不影响正确性。
